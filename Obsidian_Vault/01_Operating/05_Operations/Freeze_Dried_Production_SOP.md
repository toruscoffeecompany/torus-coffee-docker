# Freeze-Dried Production SOP — Torus Coffee Company

**Date:** 2026-08-03  
**Owner:** Miss Pink  
**Status:** Tested — version 1.0  
**Applies to:** All freeze-dried candy and fruit production

## Purpose

Standardize production of Torus Coffee Company freeze-dried products to ensure:
- Consistent quality across all batches
- Food safety compliance
- Accurate batch records
- Traceability for recalls
- Scalable production for markets and wholesale

## Scope

This SOP covers:
- Pre-production setup
- Ingredient prep and staging
- Freeze-drying cycles
- Packaging and sealing
- Labeling and batch coding
- Post-production cleanup
- Quality control checks
- Record keeping

## Safety Requirements

### Personal Protective Equipment
- Hairnet/hat
- Gloves (food-grade nitrile)
- Clean apron or smock
- Closed-toe shoes
- No jewelry on hands/arms

### Sanitation Standards
- All surfaces cleaned and sanitized before production
- Hand-wash stations available
- No food or drink in production area
- Pest control measures active
- Temperature logs maintained

### Allergen Control
- Separate prep areas for nut products if applicable
- Clean equipment between product runs
- Allergen labels on finished products
- Supplier documentation on file

[TCC]-[PRODUCT_CODE]-[DATE]-[BATCH]

Example: TCC-AB-20260803-001
  TCC = Torus Coffee Company
  AB = Aurora Bites
  20260803 = Production date (YYYYMMDD)

## Ingredient Prep

1. **Receive ingredients** — check against batch record
2. **Inspect** — no damage, correct type
3. **Weigh** — record weights in batch log
4. **Stage** — organize by production order
5. **Label** — pre-label all staging containers

## Freeze-Drying Process

### Step 1: Load Trays
- Arrange product in single layer on trays
- Leave 1-2 inches between pieces for airflow
- Do not overfill trays
- Record tray count and product weight

### Step 2: Freeze
- Set freeze dryer to -40°F or colder
- Freeze time: 4-6 hours minimum
- Verify product is fully frozen before drying phase
- Record start/end times

### Step 3: Primary Drying
- Set vacuum to 0.1-0.2 mbar
- Set shelf temperature to -20°C to 0°C
- Duration: 12-24 hours depending on product
- Monitor pressure and temperature every 2 hours
- Record readings in batch log

### Step 4: Secondary Drying
- Raise shelf temperature to 20-40°C
- Reduce pressure to <0.1 mbar
- Duration: 4-8 hours
- Product should be crisp, not chewy
- Record final moisture target: <2%

### Step 5: Unload
- Release vacuum slowly
- Remove trays carefully
- Inspect product for quality
- Record final weight
- Check moisture if using meter

## Quality Control Checks

### Visual Inspection
- [ ] Uniform color and size
- [ ] No discoloration or browning
- [ ] No freezer burn
- [ ] No broken pieces or dust
- [ ] No foreign material

### Texture Check
- [ ] Crisp, not chewy
- [ ] Crunchy when bitten
- [ ] No moisture in packaging
- [ ] No clumping

### Weight Check
- [ ] Target weight per package
- [ ] Fill tolerance: ±2%
- [ ] Seal integrity verified
- [ ] Net weight matches label

## Packaging Process

1. **Weigh product** into packaging
2. **Add oxygen absorber** if required
3. **Seal package** using heat sealer
4. **Check seal** — tug test on 10% of packages
5. **Apply label** with batch number
6. **Place in master case**
7. **Record quantities** in batch log

## Labeling Requirements

Each package must have:
- Product name
- Net weight
- Ingredients list
- Batch number
- Production date
- Best by date
- Allergen statement
- Company name/address
- Storage instructions

## Post-Production

- [ ] Clean all equipment and trays
- [ ] Sanitize production surfaces
- [ ] Dispose of waste properly
- [ ] Store finished product in cool, dry place
- [ ] Complete batch record
- [ ] File batch record in batch log binder
- [ ] Notify QA of production completion
- [ ] Update inventory spreadsheet

## Deviation Reporting

Any deviation from this SOP must be reported to QA immediately:
- Equipment malfunction
- Temperature excursion
- Packaging defect rate >2%
- Customer complaint
- Product not meeting specs

## Documentation

- Temperature logs: keep for 3 years
- Calibration records: keep on file
- Training records: all operators
