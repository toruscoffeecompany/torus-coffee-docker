# GitHub Project Workflow
_Last updated: 2026-07-22_

Lightweight reference for Torus Coffee Company workflow and project tracking on GitHub.

## Source Of Truth
- Project tracking: `09_Projects/GitHub_Projects.md`
- Branch and release rules: `09_Projects/GitHub_Workflow.md`
- Issue templates: `09_Projects/Issue_Templates.md`
- CODEOWNERS / CI hints: `09_Projects/CODEOWNERS_CI_Hints.md`

## Usage
- Match tasks to GitHub Issues and a GitHub Projects board.
- Follow the local Trello-like columns in `GitHub_Projects.md` for status fields.
- Use the labels and prefixes in `GitHub_Workflow.md` for PRs and commits.
- Open website/ops/finance/legal/growth issues with the templates in `Issue_Templates.md`.
- Apply repo rules from `CODEOWNERS_CI_Hints.md` when the repo is initialized.
