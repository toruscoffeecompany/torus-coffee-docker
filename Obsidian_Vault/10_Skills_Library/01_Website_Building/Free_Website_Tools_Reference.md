# Free Website Tools Reference

## Static site generators
- Hugo: fast SSG, Go-based, strong docs/marketing themes
- Jekyll: Ruby-based, GitHub Pages native
- 11ty/Eleventy: lightweight Node.js SSG
- Docusaurus: docs/marketing site generator from Meta
- MkDocs, mdBook, Docsify: documentation-first sites

## Free hosting
- Cloudflare Pages
- Netlify free tier
- GitHub Pages / GitLab Pages
- Render static
- Surge

## Free design/templates
- TeleportHQ free templates
- Figma free tier
- Canva free tier
- GIMP/Inkscape local editing
- Photopea browser fallback

## CMS/data
- DecapCMS / Netlify CMS
- Sanity free tier
- Supabase backend/data layer
