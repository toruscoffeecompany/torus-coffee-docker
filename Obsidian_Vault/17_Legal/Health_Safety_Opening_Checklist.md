# Health & Safety Opening Checklist — Freeze-Dried Production

**Status:** Draft  
**Date:** 2026-08-03  
**Purpose:** Pre-shift safety verification for freeze-dried snack production

## Pre-Shift Safety Check

### Facility
- [ ] All emergency exits clear and unlocked
- [ ] Fire extinguisher inspected (monthly)
- [ ] First aid kit stocked and accessible
- [ ] Floors clean and dry (slip hazard prevention)
- [ ] Lighting adequate in all work areas
- [ ] Ventilation system operational
- [ ] Temperature monitoring active (freeze-dryer room)
- [ ] No blocked aisles or tripping hazards

### Equipment
- [ ] Freeze-dryer inspected and calibrated
- [ ] Temperature sensors verified
- [ ] Vacuum pump oil level checked
- [ ] All guards/safety shields in place
- [ ] Electrical cords undamaged
- [ ] Extension cords not daisy-chained
- [ ] Knives/cutting tools sharp and stored safely
- [ ] Food prep surfaces sanitized

### PPE (Personal Protective Equipment)
- [ ] Hairnets/hats required for all production staff
- [ ] Gloves available and in good condition
- [ ] Non-slip shoes required
- [ ] Safety glasses available for cutting/prep
- [ ] Aprons/clean uniforms required

### Food Safety
- [ ] Hands washed and sanitized (20+ seconds)
- [ ] Gloves changed between tasks
- [ ] Food-contact surfaces sanitized
- [ ] No open wounds/illnesses in production staff
- [ ] Allergen awareness: freeze-dried fruit/candy processed in same facility
- [ ] Temperature logs current for:
  - [ ] Freezer storage
  - [ ] Refrigerator storage
  - [ ] Production area
- [ ] No expired ingredients in use
- [ ] Packaging materials clean and undamaged

### Chemical Safety
- [ ] Sanitizers/cleaners stored away from food areas
- [ ] SDS (Safety Data Sheets) accessible for all chemicals
- [ ] Spill kit available
- [ ] No mixing of cleaning chemicals

### Documentation
- [ ] Production log signed off
- [ ] Batch record started
- [ ] Previous batch QC results reviewed
- [ ] Recall plan accessible

## During Shift
- Report all injuries immediately
- Stop production if safety issue arises
- Document any near-misses

## Post-Shift
- [ ] All equipment cleaned and sanitized
- [ ] Waste disposed of properly
- [ ] Production area cleaned
- [ ] Temperature logs completed
- [ ] Batch record finalized
- [ ] Next shift notified of any issues
