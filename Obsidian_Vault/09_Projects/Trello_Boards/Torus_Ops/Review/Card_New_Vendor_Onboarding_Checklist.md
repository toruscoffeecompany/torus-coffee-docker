# New Vendor Onboarding Checklist

## Description
Standardized checklist for onboarding new suppliers to the Torus approved-vendor list.

## Checklist

- [ ] Collect vendor W-9 / tax info
- [ ] Request product catalog and pricing sheet
- [ ] Order sample products for evaluation
- [ ] Complete quality assessment
- [ ] Negotiate payment terms
- [ ] Add vendor to procurement system
- [ ] Set up recurring delivery schedule if applicable
