## Usage

1. Copy a template from `Templates/`
2. Move it into the appropriate list folder
3. Update metadata and fill in the checklist
4. Cross-link from the board index and list files

See [[How_to_Use_Trello_Boards|How to Use Trello Boards]] for full guide.
