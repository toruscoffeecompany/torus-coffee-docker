Security Rules

- Enable 2FA everywhere possible.
- Use unique strong passwords.
- Use a password manager if available.
- Keep API keys out of GitHub.
- Store real keys only in .env.local and hosting environment variables.
- Use .env.example for placeholder documentation only.
- Rotate keys if they are ever pasted into chat, committed, or exposed.
- Use least-privilege keys where platforms support it.
- Keep recovery email/phone current on all business-critical accounts.
